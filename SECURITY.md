# Security

Please report security vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/VusalAbdurahmanovX/Speech-to-text/security/advisories/new). Include the affected version, impact, and steps to reproduce. Do not include private recordings, transcripts, or credentials in public issues.

Security fixes target the latest release. Dependency alerts, Dependabot updates, and automated code analysis help identify issues, but do not guarantee that every vulnerability will be detected. Download releases from this repository and verify their SHA-256 checksums when needed.
